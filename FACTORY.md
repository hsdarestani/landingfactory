# A+ Landing Factory

## Goal

Turn a short client brief plus assets into several distinct, production-ready landing directions quickly, then promote the winning direction without rebuilding the project.

## Design dials

Use these three dials before implementation:

- **Variance 1–10:** 1 = quiet/centered, 10 = bold/asymmetric.
- **Motion 1–10:** 1 = micro-interactions, 10 = choreographed experience.
- **Density 1–10:** 1 = spacious marketing, 10 = compact information-rich layout.

Record the chosen values in the project brief before building. Different concepts should not vary only by color; change composition, hierarchy, type, visual metaphor and interaction language.

## Recommended stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Radix/shadcn-style accessible primitives
- Framer Motion for purposeful transitions
- Lucide for consistent interface icons
- Custom effects inspired by modern component ecosystems when they strengthen the visual concept
- Cloudflare Pages for static deployment

## Concept decision matrix

Score each concept 1–5 on:

- Brand fit
- Message clarity
- Distinctiveness
- Conversion confidence
- Mobile quality
- Performance risk
- Maintainability

The highest score is not automatically the winner; note the tradeoff and user preference, then promote one direction.
